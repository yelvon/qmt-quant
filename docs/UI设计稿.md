## 1. 设计目标

| 目标 | 说明 |
|------|------|
| **易懂优先** | 用「准备数据 → 试策略 → 验策略」等白话，技术名词放副标题或帮助里 |
| **选择优于输入** | 能下拉/勾选/预设的，不让用户手填；高级项折叠 |
| 任务导向 | 左侧导航带序号 ①–⑥，降低「不知道从哪开始」的焦虑 |
| 双引擎可见 | ③ 快速试（VectorBT）与 ④ 仔细验（NautilusTrader）分区命名 |
| 状态透明 | 每页顶部一句「这步是干什么的」+ 推荐下一步 |
| 安全默示 | 实盘默认模拟下单，真下单二次确认 |
| 桌面优先 | 宽屏布局，最小宽度 1280px |

## 2. 交互原则

### 2.1 选择优于输入

| 场景 | 不推荐 | 推荐 |
|------|--------|------|
| 股票范围 | 手输代码列表 | 下拉：沪深 A 股 / 沪深300 / 自选池 |
| 回测区间 | 手输起止日期 | 预设：近1年 / 近3年 / 近5年 / 全部 |
| 复权方式 | 英文 none/front | 下拉：前复权（回测推荐）/ 不复权 / 后复权 |
| 参数扫描 | `5,10,20` 文本 | 下拉预设：常用短均线 / 常用长均线 |
| 交易成本 | 逐项填费率 | 下拉：A股默认 / 低佣金 / 自定义（高级） |
| 验策略参数 | 手输 short/long | 下拉：来自③的候选组合（带收益摘要） |
| 选股条件 | 默认 YAML | **可视化表单**；YAML 放「高级」 |
| 财务报表 | 记英文表名 | 勾选：资产负债表 / 利润表 / … |
| QMT 路径 | 每次手输 | 设置页配置一次；数据页只显示状态 |

### 2.2 文案与命名

| 原技术名 | 用户可见名 | 副标题/帮助 |
|----------|------------|-------------|
| VectorBT 研究 | **③ 快速试策略** | 大量参数里找较优组合 |
| NautilusTrader 验证 | **④ 仔细验策略** | 按真实规则复核 |
| sync bars | **更新今日数据** | 收盘后点这个 |
| Parquet Catalog | **验策略专用文件** | 自动生成就行 |
| Dry Run | **模拟下单** | 默认开启 |
| Pipeline | **一键跑通** | 同步→试→验 串联 |

### 2.3 每页固定结构

1. **顶部说明条**：这步做什么 + 和上/下步关系  
2. **主表单**：下拉/勾选为主，默认值合理  
3. **主按钮**：一个 Primary，其余 Secondary/Ghost  
4. **结果区**：图表/表格 + 人话结论（能否采用）  
5. **下一步**：明确按钮「送到 ④」「用结果去 ③」

### 2.4 默认值

- 股票范围：沪深 A 股 · 前复权 · 近 3 年  
- 策略：双均线 · A 股默认费率 · 次日开盘成交  
- 选股：低估值动量模板 · Top 30 · 排除 ST  
- 实盘：模拟下单开启

## 3. 信息架构

```
qmt-quant
├── ① 总览           看状态 + 「今天建议做什么」
├── ② 准备数据       下拉选范围/复权/区间 → 一键同步
├── 数据浏览         横截面 / 时间序列 / K 线（与 ② 分离）
├── ③ 快速试策略     下拉选策略/参数预设 → 扫描
├── ④ 仔细验策略     下拉选③结果 → 高保真验证
├── ⑤ 选股           模板 + 下拉条件（默认可视化）
├── ⑥ 实盘           模拟/真下单，信号来源下拉
└── 全局：帮助 · 任务记录 · 设置（路径只配一次）
```

- **左侧导航**（210px）：序号 + 白话副标题  
- **顶栏**：标题 + 副标题 + 帮助 / 任务记录

## 4. 页面设计（控件级）

### 4.1 总览

- 「今天建议做什么？」：根据数据状态推荐主按钮  
- **一键跑通**：②→③→④ 向导，中间只显示进度  
- 指标卡白话化：「数据是否够用」「待你确认」  

### 4.2 准备数据

| 字段 | 控件 |
|------|------|
| 股票范围 | Select |
| 价格方式（复权） | Select |
| 历史长度 | Select |
| 财务报表 | Checkbox 组 |
| 验策略文件 | Toggle（默认开） |

按钮：**更新今日数据**（Primary）/ 全量同步 / 重试失败  

链接：**查看已同步数据 →**（跳转数据浏览）

### 4.2b 数据浏览

| Tab | 说明 |
|-----|------|
| 横截面 | 选交易日 + 复权 → 全市场表格；行点击跳转 K 线 |
| 时间序列 | 输入代码 + 日期区间 → 表格 + 下方 K 线 |
| K 线 | ECharts 蜡烛图 + 成交量；无数据提示去 ② 同步 |

### 4.3 快速试策略

| 字段 | 控件 |
|------|------|
| 选策略 | Select |
| 在哪些股票上试 | Select |
| 回测多长时间 | Select |
| 短期/长期均线 | Select 预设包 |
| 交易成本 | Select |

结果 → **送到 ④ 仔细验策略**  

### 4.4 仔细验策略

| 字段 | 控件 |
|------|------|
| 用哪组参数 | Select（来自③，带收益） |
| 按什么价格成交 | Select |
| 和什么比 | Select |

结论三态：**可以采用 / 建议复核 / 不建议**  

### 4.5 选股

默认可视化：模板 Select + PE/ROE/均线 Select + TopN Select + 排除 ST Checkbox  
YAML 仅「高级」入口  

### 4.6 实盘

模拟下单 Toggle（默认开）+ 信号来源 Select + 预览订单

## 5. 用户流程

```mermaid
flowchart LR
    A[① 总览] --> B[② 准备数据]
    B --> C[③ 快速试策略]
    C --> D[④ 仔细验策略]
    D --> E{可以采用?}
    E -->|是| F[⑥ 模拟下单]
    B --> G[⑤ 选股]
    G --> C
```

日常最短路径：**② 更新今日数据 → ③ 试策略 → ④ 验策略**
